現場速查

旅途原則：名古屋市區以早餐、喫茶、榮／名站機動為主；伊勢新宮以地方感散步點為主。
雨天備案：飯店早餐GR3x：安全版

最短決策

  • 早餐：名站選 BUCYO / Pergola；榮選 加藤珈琲 / TIAD。
  • 伊勢：河崎、月夜見宮、二見浦。
  • 新宮：神倉神社、阿須賀神社、市街巷弄、浮島の森。
  • 那智：不要只看瀑布；大門坂要列入。

拍照 tips｜只留現場用，不放詳細設定

一句話：看風景 U1、走城市 U2、吃飯拍人 U3；想黑白按 Fn，拍近物按上鍵小花，亮暗交給 ADJ。
U1｜風景 / 神社 / 海邊
  • 用來拍鳥居、神社、海邊、白天風景。
  • 一般 EV -0.3；天空太亮可降到 -0.7。
  • 大景用 iPhone 補一張，GR3x 拍細節、路人比例、木頭與石階。
U2｜城市 / 老街 / 店面
  • 這組不是抓拍預設；以 AF 構圖拍城市街景。
  • 適合招牌、老店立面、巷弄、傍晚路燈、商店街。
  • 覺得畫面太平：先用 ADJ 壓暗一點，不必把設定改重。
U3｜食物 / 人物 / 室內
  • 食物、咖啡、旅伴、室內小物。
  • 近拍按上鍵小花；白盤/白飯注意不要過曝。
  • 人物比風景重要時，優先保臉，不要為了氛圍壓太暗。
黑白臨時用
  • 神倉石階、大門坂、雨天、樹影、人影適合。
  • 用 Fn 臨時切，不佔 U 模式。
  • 如果拍完忘了切回來，先看螢幕確認 Image Control。

當地天氣速覽

來源：日本氣象廳 JMA，發布時間 2026-09-23 17:00 JST。週間預報越後面不確定性越高，出發後以最新預報為準。
